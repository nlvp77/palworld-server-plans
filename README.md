## 固定计费和动态计费怎么选

每天固定时间段开服，选固定计费，花费可预期，不用担心某天人多把 CPU 用量拉高。

一周只开一两次、或者想起来才开，选动态计费。基础价约为表价一半，不玩的时候几乎不产生 CPU 费用，E5 档 35 元/月起就能挂着一个服。

## 开服要几步

雨云的开服流程分三条路，按你熟悉的方式挑一条。

**Windows 一键部署（新手推荐）**

1. 购买游戏云 VPS，系统选 Windows 2019
2. 本机用 `mstsc` 远程桌面连上去
3. 打开 PowerShell，运行 `iex (irm 'https://tc2.zeruns.tech/other/pal-server-install.ps1')`
4. 看到 `PalServer deploy success!` 就是装完了
5. 到雨云控制台做 NAT 端口映射，把内网 **8211** 映射出去，把公网地址加端口发给朋友

整条流程走下来不到 20 分钟，不需要懂 Linux 命令。

**Linux 一键部署**

系统选 Ubuntu 最新版，SSH 登录后执行 `wget -O - https://tc2.zeruns.tech/other/pal-server-install.sh | sh`。装完服务会自动开机自启，服务器重启后不用手动拉进程。

**面板服**

买面板服，游戏类型选“幻兽帕鲁”，开启实例，面板控制台右侧显示的“对外地址和端口”就是服务器地址，形如 `hm.rainplay.cn:31740`，直接发给朋友。

改世界参数的话，进 `pal/Pal/Saved/Config/LinuxServer/` 编辑 `PalWorldSettings.ini`。这个文件初始是空的，要先把 `pal/DefaultPalWorldSettings.ini` 的内容整个复制进去再改，直接粘注释版进去可能不生效。改完重启实例。经验倍率、捕获率、最大玩家数、死亡惩罚都在这个文件里。

朋友连不上，九成是端口没映射。先去控制台检查 8211 的 NAT 规则，再核对发出去的地址和端口。

## 开服之后最容易被忽略的三件事

开服只是开始，长期开的成本在维护上，这部分前排教程基本不讲。

**内存泄漏。** 幻兽帕鲁有跑了很久内存持续上涨的老问题，最后卡顿甚至崩溃。两个应对办法：给 8G 的机器额外配 **8–12G SWAP** 当保险；或者用脚本在内存占用超过 **90%** 时自动重启帕鲁进程，回档大约 **10 秒**，玩家基本无感。说到底，直接上 16G 比事后打补丁省心。

**存档备份。** 存档在 `Pal/Saved` 目录下，养成定时打包的习惯。手动备份一条命令就够：把整个 `Saved` 目录打包成带日期的压缩包，再拉回本地一份。

**端口安全。** 游戏 REST API 端口 **8212**、RCON 端口 **25575**，以及任何进程控制接口，都不要直接暴露到公网。这些端口没有强认证，扫到就能接管你的服务器。

想要可视化管理的，可以看看 PST Enhanced 这类工具：解析 `.sav` 存档加官方 REST API 和 RCON，能看玩家、公会、帕鲁、背包，能定时备份、平滑重启、崩溃后自动拉起，还能接 QQ 机器人查询状态。要注意它解析 `Level.sav` 时短时间会吃 **1GB 到 3GB 内存**，装工具的那台机器得留足资源，默认 Web 端口是 8080。
